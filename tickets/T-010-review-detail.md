# T-010: 復習詳細画面（F-04）

- **Status**: TODO
- **Phase**: 4 / **Track**: C
- **依存**: T-009（復習一覧）
- **要件**: 要件定義書 §4.5（F-04）
- **担当パス**: `app/review/[sessionId]/**`, `components/review/**` のみ

## ゴール

過去セッションの各問題の詳細を確認し、間違えた問題だけに絞って復習できる画面を作る。

## タスク

- [ ] `/review/[sessionId]` ページを作成する
- [ ] セッションのサマリー（実施日時・正解率・正解数）を表示する
- [ ] 問題ごとの詳細リスト:
  - 問題文 / 自分の回答 / 正解 / 正誤 / 解説
  - **当時の選択肢並び順**（`session_answers.shuffled_options`）で表示する
  - 未回答は「未回答（不正解扱い）」と明示
- [ ] **「間違えた問題だけを復習」フィルタ**（不正解＋未回答のみに絞り込むトグル）
- [ ] 本人のセッション以外・存在しない sessionId は 404

## 完了条件

- 各セッションの問題ごとの正誤・解説が確認できる
- 間違えた問題のみに絞り込める
- 出題時と同じ選択肢の並びで再現される
