# T-006: 模擬テスト実施画面（F-02）

- **Status**: TODO
- **Phase**: 2 / **Track**: A
- **依存**: T-004（認証）, T-005（共通ロジック）
- **要件**: 要件定義書 §4.3（F-02）
- **担当パス**: `app/mock/**`, `components/mock/**` のみ

## ゴール

65 問の本番形式模擬テストを開始から提出まで実施できる画面を作る。

## タスク

- [ ] `/mock`: 開始画面（テストの説明・注意事項・「模擬テスト開始」ボタン）
- [ ] 開始時に `createSession('mock', 65)` を呼びセッションを生成する（未解答優先＋選択肢シャッフルは T-005 が担当済み）
- [ ] 出題 UI（1問ずつ順送り）
  - 進捗表示（例: 12 / 65）
  - 「前へ」「次へ」で移動でき、選択済みの回答は保持される
  - 問題一覧（回答済み／未回答の俯瞰）があると望ましい（任意）
- [ ] **テスト中は正誤・解説を一切表示しない**
- [ ] 「採点する」で提出できる（未回答があっても可・確認ダイアログを出す）
  - `finishSession` を呼び、未回答は不正解扱い
  - 完了後 `/mock/result/[sessionId]` へ遷移する
- [ ] 進行中の mock セッションがある状態で `/mock` を開いたら再開を提案する（任意）

## 完了条件

- 開始のたびに出題される問題・選択肢順が変わる
- テスト中に正誤・解説が見えない
- 未回答があっても提出でき、提出後に結果画面へ遷移する（T-007 未完成の間は遷移先が 404 でも可）

## 並行開発メモ

- 結果画面（T-007）とはページを分離してあるので、T-007 の完成を待たずに実装・マージしてよい。
