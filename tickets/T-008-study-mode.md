# T-008: 全問学習モード（F-03）

- **Status**: TODO
- **Phase**: 3 / **Track**: B
- **依存**: T-004（認証）, T-005（共通ロジック）
- **要件**: 要件定義書 §4.4（F-03）
- **担当パス**: `app/study/**`, `components/study/**` のみ

## ゴール

問題プール全体（193問）を 1 問ずつ即時採点で反復学習できる画面を作る（フラッシュカード形式）。

## タスク

- [ ] `/study`: 学習開始画面（進捗サマリー・出題順の選択・「学習開始」）
- [ ] 出題順の切り替え: **未解答優先（デフォルト）** / ランダム / id 順
- [ ] 1 問回答するごとに、即座に正誤・正解・解説を表示する
- [ ] 「次の問題へ」で進む
- [ ] 回答ごとに `saveAnswer` を呼び、`user_question_stats` に反映する（mode='study' のセッションとして記録。→ 模擬テストの未解答優先ロジックにも自動反映される）
- [ ] 中断・再開: 途中でページを離れても、次回 `/study` を開いたら続きから再開できる（進行中の study セッションを再利用する等）
- [ ] 選択肢は出題ごとにシャッフルする（T-005 の shuffle を使用）

## 完了条件

- 回答直後に正誤・解説が表示される
- 解いた問題の正誤が `user_question_stats` に反映される（模擬テストの出題優先度に効く）
- 中断後に再開できる
