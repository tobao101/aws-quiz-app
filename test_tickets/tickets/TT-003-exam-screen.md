- **Status**: DONE
- **依存**: TT-002

## ゴール

65問を1問ずつ回答できる画面を作る。DB保存はせず、回答状態はすべてクライアント側（React state）で保持する。

## タスク

- [x] `/exam`: 開始画面（簡単な説明・「模擬テスト開始」ボタン）
- [x] 開始時に TT-002 の `selectQuestions` + `shuffleOptions` を呼び、65問分の出題データ（シャッフル済み選択肢を含む）を state に生成する
- [x] 出題 UI（1問ずつ順送り）
  - 進捗表示（例: 12 / 65）
  - 「前へ」「次へ」で移動でき、選択済みの回答は state 上で保持される
- [x] **テスト中は正誤・解説を一切表示しない**
- [x] 「採点する」ボタンで提出できる（未回答があっても提出可・確認ダイアログを表示する。未回答は不正解扱い）
- [x] 提出時に、全65問分の「自分の回答・正解・正誤」を集計し、結果画面（TT-004）が表示に使うデータを渡す
  - `test-app/app/exam/layout.tsx` に `ExamProvider`（React Context, `test-app/components/exam/ExamContext.tsx`）を配置し、`/exam` と `/exam/result` の間でページ遷移をまたいで state を共有する方式で実装（sessionStorage ではなく Context を採用）
