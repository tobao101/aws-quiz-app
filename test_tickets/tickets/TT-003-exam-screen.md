# TT-003: 出題・回答画面

- **Status**: TODO
- **依存**: TT-002
- **担当パス**: `test-app/app/exam/**`, `test-app/components/exam/**`

## ゴール

65問を1問ずつ回答できる画面を作る。DB保存はせず、回答状態はすべてクライアント側（React state）で保持する。

## タスク

- [ ] `/exam`: 開始画面（簡単な説明・「模擬テスト開始」ボタン）
- [ ] 開始時に TT-002 の `selectQuestions` + `shuffleOptions` を呼び、65問分の出題データ（シャッフル済み選択肢を含む）を state に生成する
- [ ] 出題 UI（1問ずつ順送り）
  - 進捗表示（例: 12 / 65）
  - 「前へ」「次へ」で移動でき、選択済みの回答は state 上で保持される
- [ ] **テスト中は正誤・解説を一切表示しない**
- [ ] 「採点する」ボタンで提出できる（未回答があっても提出可・確認ダイアログを表示する。未回答は不正解扱い）
- [ ] 提出時に、全65問分の「自分の回答・正解・正誤」を集計し、結果画面（TT-004）が表示に使うデータを渡す
  - DB を使わないため、React state のリフトアップ／Context、または `sessionStorage` など、ページ遷移をまたいでも結果データを渡せる方法で実装する（リロードで消えるのは仕様どおりでよい）

## 完了条件

- 「模擬テスト開始」のたびに出題順・選択肢順が変わる
- テスト中に正誤・解説が一切見えない
- 未回答があっても「採点する」で提出できる
- 提出後、結果画面（TT-004）へ必要なデータを渡した状態で遷移できる

## メモ

- DB・API Route・サーバーアクションは使わない。すべてクライアントコンポーネントで完結させてよい。
- リロード時の再開・進捗保存は対象外（最初からやり直しでよい仕様）。
