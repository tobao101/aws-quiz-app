# チケット管理ファイル（テスト版）— DB/認証なし簡易模擬テストアプリ

- このフォルダは `tickets/`（本番版・要件定義書ベース）とは**別スコープ**の、最小構成プロトタイプ用チケット管理ファイルです。
- 問題データ: [claude2/quiz_data.json](../claude2/quiz_data.json)（193問）をそのまま流用する
- 個別チケット: [tickets/](./tickets/) フォルダ（1チケット = 1ファイル）

## スコープ

- 問題プール（193問）から **65問をランダム抽出**し、**選択肢もランダム配置**して出題する
- 65問すべてに回答し終えたら、**正解率（正解数 / 65）**と**問題ごとの正誤・自分の回答・正解・解説**を表示する
- **ログイン認証・データベースは使用しない**（履歴保存・複数端末同期・未解答優先ロジック・復習機能・ダッシュボードは対象外）
- ページをリロードした場合は保存せず**最初からやり直し**でよい（localStorage 等の永続化も行わない）
- プロジェクトは `test-app/`（リポジトリルート直下、本番版が将来使う可能性のあるルート直下の `app/` 等とは衝突しない専用フォルダ）に作成する

## 技術構成

| 分類           | 技術                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------- |
| フレームワーク | Next.js（App Router）/ TypeScript / Tailwind CSS                                          |
| データ         | `claude2/quiz_data.json` を `test-app/` 内にコピーしてビルド時に静的 import（DB不要） |
| 状態管理       | React state（クライアント側のみ、DB書き込みなし）                                         |
| 認証           | なし                                                                                      |
| ホスティング   | ローカル開発のみ想定（`npm run dev`）                                                   |

## 開発の流れ

このスコープは小規模なため並行トラックには分けず、**TT-001 → TT-002 → TT-003 → TT-004 の順に直列で実装する**。

```
TT-001（プロジェクト初期化） → TT-002（出題ロジック） → TT-003（出題・回答画面） → TT-004（結果画面）
```

## 本番版（`tickets/`）との関係

- 本チケット群はあくまでプロトタイプ・検証用。将来 `tickets/` 側の本番要件（認証・DB・復習機能・ダッシュボード等）を実装する際、`test-app/lib/quiz/` の出題・シャッフルロジックは `lib/quiz/` の実装の参考にできるが、そのまま流用はしない（DBアクセスの有無で関数シグネチャが変わるため）。
- ファイルパスが重ならないよう、本チケット群は必ず `test-app/**` 配下のみを変更する。
